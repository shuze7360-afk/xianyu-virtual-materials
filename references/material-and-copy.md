# 资料整理与营销文案

## 一、资料整理阶段（决定卖点）

### 做法
1. **先摸底再动手**：用 Python 批量提取所有文件的文字摘要（docx/pptx 用 python-docx / python-pptx，PDF 用 pypdf），扫描版 PDF 无文字层就提取内嵌图片抽查内容。
2. **内容验真**：营销文案里的每个卖点都要有实物支撑——"手写笔记"要打开看一眼确认真是手写；"逐年详解"要确认真的每份都有答案。归属院校要交叉验证（卷头科目代码 / PPT 内署名计数），防止把外校资料误标进本项目（实战教训：曾把外校考纲误当成这套资料的一部分写进文案）。
3. **结构化编号**：`01-xxx / 02-xxx` 按买家使用顺序编号；文件名改语义化名称并标注页数/格式。
4. **随包放《00-购买必读·使用指南》**：目录导航 + 复习路线 + 文件打开提示 + 免责声明——挡售后纠纷的第一道墙。
5. **文件名里的特殊空白要排查**：`\xa0` 不间断空格会导致脚本按名字找文件失败，重命名前先打印 repr 看真实字符。

### 卖点挖掘经验
同类文件逐个抽查内容，最值钱的往往是最不起眼的（实战中翻出过"真题逐题手写答案"页、"逐年手打详解"这种碾压同行的硬货）。

## 二、营销文案阶段

### 结构模板（痛点→王牌→锚点→规则→行动）
1. **4 条痛点**开场；
2. **2-3 个"王牌"板块**前置（按买家最痛的排序：真题/手写答案永远排最前）；
3. **价格锚点拆解**：逐项报"市面散买价"→合计→打包价约 N 折；
4. **发货规则显眼位置**：虚拟资料不退不换 + 确认收货后秒发链接（防白嫖）；
5. **合规红线**：不用「保过 / 押题命中率100% / 内部渠道 / 命题组」；描述**不能含 emoji**（闲鱼校验会拦截，见 pitfalls.md #1；✅ 在部分字体还渲染成豆腐块，勾号统一用 √）。

完整可套用文案见 [listing-template.md](listing-template.md)。

### 防剧透写法
- **详情页图只给"凭证"不给"内容"**：卷头（校名/科目/代码可读）+ 正文打码；文件清单截图可放，原卷/答案整页不放。
- **文案只说年份、板块、题型结构**，不列举任何具体题目；把"详情页不剧透，拍下看完整原卷"本身写成卖点。
- 题型级提示（如"以简答和设计题为主"）属结构信息，保留与否交用户裁定。
- 反例代价：首版把真题逐题列举 + 原卷照片挂详情页，价值直接缩水，下架重发一遍。

### 定价逻辑
- 先用 `search_market` 抓同类商品行情再定价：基础款看价格带下限~上限，**独家整理内容 = 价格带上限 × 1.5~2**（资料独特性越强越取上限）。
- 被砍价时**不降价、改送体验**（送单页预览 / 后续更新换购），保住价格锚；把让利变成价值感，而不是折扣惯病。
