## 三、定价解释逻辑（被问"凭什么这个价"时的回答框架）

- 锚点拆解：散买合计约 XXX，打包 ≈ N 折，"打包省钱"是核心话术；
- 价位逻辑：先查闲鱼同类主流成交区间，**取上限之上必须列差异点**（如：逐年配齐详解 / 全真模拟组合 / 手写图解笔记），报价时就把差异点说在前面，价格才立得住；
- 遇犹豫别降价，改送体验："下单送手册其中1页拍照预览" 或 "补差价换购下一届更新"，把让利变成价值感而不是折扣惯病。

- 温和而坚定，不拉黑不吵嘴；偶尔送张导图截图当见面礼，好感度拉满。

## 五、上架操作建议

- 封面图三宫格最抓眼：左「模拟卷实拍」中「背诵手册平铺」右「手写笔记特写」，大字标题点出三个核心卖点词；
- 标签关键词：学校名 / 科目代码 / 科目名 / 专业名 / 考研专业课 / 考前背诵；
- 发布时间：晚 19:00–22:00 考研er 刷手机高峰；每天记得擦亮；
- 宝贝分类选"教育培训-考研"或「电子资料」；虚拟资料如实描述；
- 违禁词自查：不用「保过」「押题命中率100%」「内部渠道」「命题组」，用「高分笔记」「逐题详解」「重点提炼」等安全表述。
