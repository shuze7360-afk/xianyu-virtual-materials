# 自动发货流程（auto-delivery）

把 SOP 里"确认收货后人工代发"升级为全自动：定时轮询闲鱼网页版消息页，自动识别"已确认收货"的买家会话，判定商品并发送网盘链接话术。**本目录脚本为通用脱敏版，可直接套用：换 Cookie、写一份商品配置即可运行。**

## 为什么网页版只能这样做（逆向结论）

- 闲鱼网页版**没有卖家订单列表**：站点路由只有 `bought` / `order-detail`，个人中心"我卖出的"入口点击无响应——卖家侧不存在可程序化的订单数据源
- 唯一可用的"已确认收货"信号是 **/im 会话列表的「交易成功」芯片**（列表项 innerText 形如「买家昵称\n交易成功\n快给ta一个评价吧～\n10-05」）
- 聊天内订单卡有价格、无商品标题 → 商品归属只能靠聊天内容判定
- 页面类名带哈希后缀且随发版变化（如 `conversation-item-hover--sNtmkHXC`）→ 脚本一律前缀匹配 `[class*="..."]`，并提供 probe 模式 dump 现场兜底

## 流程

```
每小时定时触发（ZCode/Task Scheduler/手动均可）
  → 打开 goofish.com/im，扫描会话列表「交易成功」芯片
  → 点开会话，取聊天全文
  → 三重防线全过才发货：
      ① 芯片 = 交易成功（买家已确认收货，防白嫖）
      ② 会话历史不含网盘链接标记 —— "会话含链接"即"已发货"判据，
         天然兼容历史人工发货的去重，不需要预置台账
      ③ 本地台账 delivery_ledger.json 无记录
  → 商品判定：match 关键词强匹配 → price 价格签名弱匹配；命中不唯一一律跳过交人工
  → textarea 逐字拟人输入 + Enter 发送 → 回读会话验证链接出现 → 写台账
```

## 防风控设计

- 单次运行最多发 2 条、每日上限 6 条（常量可调）
- 两条消息间隔 40–80 秒随机
- `press_sequentially` 逐字拟人输入
- 默认有头浏览器（headless 更易触发风控；可用环境变量切换，自担风险）
- 发送后回读验证，失败不写台账、下轮自动重试；无法唯一判定商品时宁可跳过

## 安装与运行

依赖：Python 3.10+、`playwright`（装好后 `playwright install chromium`）、闲鱼网页版登录 Cookie（JSON 数组格式，可用 [FishClaw MCP](https://github.com/7070126/fishclaw) 等任意登录流程产出）。

```bash
python auto_delivery.py                 # check：只检测不发送，输出报告（默认，最安全）
python auto_delivery.py --mode send     # send：检测 + 自动发送
python auto_delivery.py --mode probe    # probe：页面结构侦察（页面改版后先跑这个）
```

- 退出码：`0` 正常（含无事可做）｜`3` 登录失效需重新扫码｜`4` 页面结构不认识｜`5` 有发送失败
- 环境变量：`XIANYU_COOKIES` 指定 Cookie 文件路径（默认 `~/.goofish-auto-delivery/xianyu_cookies.json`）；`XIANYU_HEADLESS=1` 无头模式
- 每次运行在 `reports/` 生成 JSON 报告（成功买家/跳过原因/错误），`auto_delivery.log` 追加日志

## 配置：listing_links.json

参照 [`config.example.json`](config.example.json) 编写：

| 字段 | 说明 |
|---|---|
| `match` | 聊天内容**强匹配**关键词（数组）。务必选标题里独一无二的词，警惕与其他商品标题撞词 |
| `price` | **弱匹配**价格签名（文本去空白后子串匹配）。别配太短（如 "3" 必然误命中）；仅在关键词零命中时启用 |
| `url` / `pwd` / `days` | 发货网盘链接、提取码、有效期（写进发货话术） |
| `item_id` | 备注用；换链/新商品只改本文件，脚本无需动 |

## 已知边界

- 买家确认收货到发货存在定时周期级别的延迟（建议 1 小时）
- 会话列表深翻页未做：在售商品数较少时足够
- 闲鱼官方"自动发货"（发布时添加链接、付款即发）是 APP 端功能，且"付款即发"与"确认收货后发货"的防白嫖策略相悖，故未采用
- 更多环境级坑见 [`../references/pitfalls.md`](../references/pitfalls.md)（35 条）

## 合规声明

- 仅供个人学习交流与自动化效率提升；自动化操作**自己的**账号、给**自己的**买家发货
- 请遵守闲鱼平台规则；频繁自动化操作存在账号风控风险，自行评估
- 本仓库不含任何真实账号数据（商品 ID / 链接 / 提取码 / 买家信息均已脱敏或移除）
