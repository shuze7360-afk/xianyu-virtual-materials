# xianyu-virtual-materials

闲鱼虚拟资料（考研/学习类数字商品）全流程 SOP，封装为 [ZCode](https://zcode.ai) skill。沉淀自三个实战验证过的项目（资料类×2 + 服务类×1），**已完全脱敏**：所有院校、科目代码、商品 ID、分享口令、个人路径均以占位符代替，换成自己的信息即可套用。

## 覆盖流程

```
资料整理验真 → 营销文案 → 百度网盘MCP上传分享 → 闲鱼上架 → 售后代发
```

- **资料整理**：批量摸底、内容验真、结构化编号、《00-购买必读》
- **营销文案**：痛点→王牌→锚点→规则→行动，防剧透原则，定价逻辑，完整文案模板
- **网盘发货**：MCP 上传（`/apps/` 路径）、分享链接（365天优先、4位提取码）
- **闲鱼发布**：FishClaw MCP 标准流程 + 发布前四查；服务类商品的网页版分类限制逆向破解（Playwright route 改写）
- **售后运营**：确认收货后代发、发货话术模板、到期续链
- **踩坑速查**：25 条环境级坑（闲鱼校验、MCP 参数、浏览器自动化、代理劫持……）

## 安装

```bash
# 克隆到 ZCode 的 skill 目录（~/.agents/skills/）
git clone https://github.com/shuze7360-afk/xianyu-virtual-materials.git ~/.agents/skills/xianyu-virtual-materials
```

新会话中提到"闲鱼卖资料"、"上架虚拟资料"、"考研资料变现"、"网盘发货"等即自动触发；也可 `/skill xianyu-virtual-materials` 强制加载。

## 核心红线

发布前必须把封面图、细节图、文案全文交人工审核，拿到明确的"确认发布"才能上架——"继续"、"开工"不算授权。
