# xianyu-virtual-materials

闲鱼虚拟资料（考研/学习类数字商品）全流程 SOP，封装为 [ZCode](https://zcode.ai) skill。沉淀自三个实战验证过的项目（资料类×2 + 服务类×1），并已完成"**确认收货后全自动发货**"升级（2026-10 实战验证，含数据整理类商品的隐私合规自检）。**已完全脱敏**：所有院校、科目代码、商品 ID、分享口令、买家信息、个人路径均以占位符代替或移除，换成自己的信息即可套用。

## 覆盖流程

```
资料整理验真 → 营销文案 → 百度网盘MCP上传分享 → 闲鱼上架 → 售后代发 → 全自动发货
```

- **资料整理**：批量摸底、内容验真、结构化编号、《00-购买必读》
- **营销文案**：痛点→王牌→锚点→规则→行动，防剧透原则（含统计类商品的"凭证型细节图"），定价逻辑，完整文案模板
- **网盘发货**：MCP 上传（`/apps/` 路径）、分享链接（365天优先、4位提取码）；token 过期免重启自救（REST 直连上传 + SSE 网关建链）
- **闲鱼发布**：FishClaw MCP 标准流程 + 发布前四查；服务类商品的网页版分类限制逆向破解（Playwright route 改写）；发布页一键填表+发布脚本模板
- **售后运营**：确认收货后代发、发货话术模板、到期续链
- **全自动发货**：/im 会话芯片检测已确认收货买家 → 三重防线 → 拟人输入自动发送 → 台账去重（详见 [auto-delivery/](auto-delivery/)）
- **数据类商品合规**：个人隐私（PII）全文扫描自检、可售判定、"仅提供去向不提供个人信息"话术
- **踩坑速查**：35 条环境级坑（闲鱼校验、MCP 参数、浏览器自动化、代理劫持、登录态误判……）

## 安装

```bash
# 克隆到 ZCode 的 skill 目录（~/.agents/skills/）
git clone https://github.com/shuze7360-afk/xianyu-virtual-materials.git ~/.agents/skills/xianyu-virtual-materials
```

新会话中提到"闲鱼卖资料"、"上架虚拟资料"、"考研资料变现"、"网盘发货"、"闲鱼自动发货"等即自动触发；也可 `/skill xianyu-virtual-materials` 强制加载。

## 核心红线

发布前必须把封面图、细节图、文案全文交人工审核，拿到明确的"确认发布"才能上架——"继续"、"开工"不算授权。
